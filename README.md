# 诗云 · 宇宙终极算力行为艺术 (The Poetry Cloud)

> *“把两万零九百九十二个汉字排成顺序，把等待交给宇宙。<br>从今日子夜零点开始，以固定五微秒（每秒二十万首）的极速，<br>沿着每一种可能，步步向前，终将走到李白的月光。”*  
> —— 致敬刘慈欣科幻小说《诗云》与博尔赫斯《巴别塔图书馆》

---

## 🌌 作品简介

《诗云》是一件探讨**时间尺度、离散数学、语言组合与人类审美价值**的单页数字艺术作品。

在刘慈欣的小说《诗云》中，神级文明掌握了超越人类的宇宙算力，却写不出超越李白的诗篇；于是神决定毁灭整个太阳系，将其全部质量制成光介质量子存储器，以纯粹的穷举法写出所有可能的诗歌。

本项目将这一科幻构想在现代计算机浏览器中真正落地：
* 基于 Unicode CJK 基本汉字区间（`0x4e00` 至 `0x9fff`，共 **20,992** 个汉字），构建了一套无损可逆的 **Base-20992** 宇宙离散数制空间；
* 五言绝句（20 字）的全部排列组合状态空间高达：
  $$20992^{20} \approx 1.71 \times 10^{86} \text{ 首}$$
* 这一数字，已经超越了全宇宙可观测原子总数（约 $10^{80}$ 个）。

## ✨ 核心特性

1. **严格锚定物理时钟**  
   程序不进行伪随机生成，而是严格从每日子夜 `00:00:00.000` 起算，依据浏览器物理时间的流逝进行确定性大数推算。
   
2. **极速理论微秒步长**  
   锁定现代计算机高精度计时器（High Resolution Time）理论极限：**5 微秒（$5\,\mu\text{s}$，即 200,000 首/秒）**。一秒二十万生灭，在虚空的长河中步步前行。

3. **确定性大数里程表**  
   任何人在任何设备的浏览器中打开此网页，只要本地时间相同，看到的都是由同一个物理时刻决定的同一首诗（前段为深沉稳定的「一」字前缀，末尾字符随物理时钟微秒级飞速进位）。

4. **千古绝唱重逢罗盘**  
   精选九首最具代表性的五言绝句：
   * 《山村咏怀》〔宋 · 邵雍〕（01 号先行者）
   * 《静夜思》〔唐 · 李白〕
   * 《春晓》〔唐 · 孟浩然〕
   * 《登鹳雀楼》〔唐 · 王之涣〕
   * 《江雪》〔唐 · 柳宗元〕
   * 《鹿柴》〔唐 · 王维〕
   * 《寻隐者不遇》〔唐 · 贾岛〕
   * 《相思》〔唐 · 王维〕
   * 《乐游原》〔唐 · 李商隐〕  
   在对数域（$\log_{10}$）无损精度测算重逢所需的精确年数、等效宇宙年龄倍数（以 138 亿年为单位），以及对应所处的天体物理演化纪元（退化恒星纪元、质子衰变纪元、恒星级黑洞蒸发时代、终极热寂虚空）。

5. **「一」字开头的数学浪漫**  
   北宋邵雍的《山村咏怀》（*“一去二三里，烟村四五家。亭台六七座，八九十枝花。”*）首字为「一」，其 Unicode 码点恰为 `0x4e00`（偏移量为 0）。它位于整个宇宙状态空间的最前沿 $1/20992$ 处，重逢时间为 **$1.46 \times 10^{68}$ 年**，比李白的月光提早了整整六万多倍时间。

6. **纯单文件零依赖（Zero Dependencies）**  
   所有水墨泥金视觉样式、算法核心与 Canvas 汉字微尘星云粒子动画均完整内联在单个 `index.html` 中，支持直接双击运行或部署到任何 Web 服务器。

---

## 🚀 部署与使用

只需将仓库中的 `index.html` 放置于任何静态服务器根目录即可：
* **GitHub Pages**：在仓库 Settings -> Pages 中选择 `main` 分支根目录，即可开启在线访问。
* **本地运行**：双击 `index.html` 在任何现代浏览器（Chrome、Edge、Safari、Firefox）中离线打开。
